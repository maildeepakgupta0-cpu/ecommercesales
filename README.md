# Ecommerce Sales Dashboard

An interactive Power BI dashboard designed to analyze and track key performance indicators (KPIs) for an ecommerce business. This project visualizes sales performance, customer trends, profitability, and order distributions across various dimensions.

## 📊 Dashboard Overview

The dashboard is structured into a dark-themed, high-impact user interface containing the following core metrics and visualizations:

### Key Performance Indicators (KPIs)
* **Total Sales Amount:** 438K
* **Total Profit:** 37K
* **Total Quantity Sold:** 5,615 units
* **Average Order Value (AOV):** 121.01K

### Core Visualizations & Insights
* **Sales by State:** Horizontal bar chart highlighting geographical sales performance (e.g., Maharashtra, Madhya Pradesh).
* **Quantity by Category:** Donut chart showing product demand breakdown across **Clothing** (dominant at ~62.6%), **Electronics**, and **Furniture**.
* **Monthly Profitability:** Vertical column chart tracking the trend of `Sum of Profit` across months from January to December.
* **Customer Analysis:** Comparison of total sales driven by top customers (e.g., Harish, Madhav, Madan Mohan, Shiva).
* **Payment Mode Preference:** Donut chart tracking transaction channels, highlighting **COD** (43.74%), **Credit Card** (11.97%), **Debit Card** (13.2%), and **UPI** (20.61%).
* **Profitability by Sub-Category:** Breakdown of individual item segments (Printers, Bookcases, Saree, Accessories, Tables) ranked by profit contributions.

## 📁 File Structure

* `ecommerce.pbix` - The primary Power BI Desktop file containing data models, relationships, and visual layouts.
* `README.md` - Documentation and project guide.

## 🚀 How to Use
1. Clone or download this repository.
2. Install [Power BI Desktop](https://microsoft.com).
3. Open the `ecommerce.pbix` file to explore, interact with filters (Quarterly, Category-specific slicers), or refresh data connections.
